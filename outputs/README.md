# Released outputs

These generated figures, tables, source data, benchmarks, and video are
licensed under CC BY 4.0; see [`../LICENSE-DATA`](../LICENSE-DATA).

The public output archive consists only of `manuscript/`, `video/`, this
README, and `SHA256SUMS`. It contains final manuscript products, compact source
data, and one animation. Any other subdirectory present in a working copy is
local scratch state and is excluded from GitHub and Zenodo.

## `manuscript/figures/`

Figures 3--12 are stored as publication PDFs. Each figure has a JSON sidecar
that records its available inputs, rendering or scientific contract, and file
hashes.
Figure 4 additionally includes its plotted forecast CSV, and Figure 7 includes
the five-seed summary CSV.

Figures 1 and 2 are manuscript-native diagrams and are not generated by this
repository.

Figures 10--12 are rendered together from the compact
`artifacts/zc-v3/manuscript/steering/final_plot_data/` bundle.

## `manuscript/tables/`

The directory contains the TeX fragment for Table 1 and its JSON provenance
sidecar. Table 1 reports the training-only XAI comparison.

## `manuscript/source_data/`

Only small values used directly by the paper are retained:

- `figure5/`: the complete five-seed predictive-skill results;
- `diagnostics/`: the AGOP field-mass audit cited in the interpretation.

These files are retained because they make quantitative statements auditable
without extracting values from a PDF.

## `manuscript/benchmarks/`

`xai_cpu4/` contains the compact reports and log for the four-core XAI timing
benchmark quoted in the manuscript. Large gradient-row caches and other
reproducible benchmark intermediates are intentionally excluded.

## `video/`

The release contains exactly one animation:

```text
zc_standardized_ocean_currents.mp4
zc_standardized_ocean_currents.json
```

It shows standardized SST anomaly and standardized depth-averaged ocean
currents from public `zc-v3` data. The JSON sidecar records the normalization,
frame selection, display limits, and output hash.
